产品介绍

把「一张张另存为」变成一次勾选

详情页里的商品图片分散在主图、SKU 缩略图、详情长图和轮播背景中，格式与尺寸各不相同。 图提取把它们收拢到一处，整理素材不再依赖重复的手工操作。

图片太分散

主图、缩略图、详情长图与背景图散落在页面不同位置，靠肉眼找齐容易漏图。

无法批量保存

浏览器右键只能一张张另存为，几十张素材整理下来耗时且容易命名混乱。

格式不统一

jpg、webp、png 混在一起，上传到其他平台前还要逐个转换格式。

核心功能

六项能力，覆盖从提取到下载的全流程

所有处理都在本地浏览器内完成，不上传、不留存你的商品图片。

一键提取

自动扫描页面内所有商品图，兼容 srcset 与各类懒加载属性，主图、缩略图、背景图都能收进来。

智能过滤

按真实像素尺寸与特征词排除图标、logo、占位图与 1×1 像素图，只留下可用的商品素材。

集中预览

在新标签页以响应式网格展示全部图片，缩略图、像素尺寸与文件名一目了然。

自由勾选

支持全选、反选与单张勾选，实时显示已选数量，只下载真正需要的那几张。

统一 PNG

jpg、webp、gif 自动通过 canvas 转为 PNG，遇到跨域图片在后台抓取解码，不污染画布。

批量下载

一键保存到浏览器默认下载目录，文件名自动编号为「商品图_001.png」，进度与结果实时反馈。

安装步骤

四步装好，刷新页面即可使用

无需构建、无需依赖，安装过程不超过一分钟。

安装完成后打开任意商品详情页，右下角会出现「获取图片」按钮；之后升级插件只需回到扩展页点击刷新。

  1. 1

    下载并解压插件

    获取插件压缩包后解压到一个固定文件夹，之后升级插件时指向同一位置即可。

  2. 2

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    打开页面右上角（部分版本在左上角）的「开发者模式」开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择包含 manifest.json 的那一层文件夹。

现在就把详情页图片一次拿走

安装后刷新商品详情页，右下角就会看到「获取图片」按钮。
